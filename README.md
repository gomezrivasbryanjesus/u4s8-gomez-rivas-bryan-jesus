# U4S8 — Gomez Rivas Bryan Jesus

## Demo en vivo (producción)
https://u4s8-gomez-rivas-bryan-jesus.onrender.com

## Qué hace este proyecto
Este proyecto permite crear servicios en una base de datos MySQL utilizando una interfaz, a los que se les puede añadir un nombre, descripción, precio y categoria.

## Stack técnico
Django + MySQL (Aiven) + Tailwind CSS + Render

## Cómo se prueba el aislamiento por usuario
Paginación invalida validada.
Resultados de busqueda vacios e incorrectos validados.
Añadir, editar y eliminar servicios validado.

## Historial de unidades
- Unidad 1: portafolio estático con HTML5 + Tailwind
- Unidad 2: modelo Servicio migrado a MySQL, deploy dinámico en Render
- Unidad 3: CRUD completo con ModelForms + autenticación y sesiones
- Unidad 4: paginación, búsqueda, UI review y defensa final
